## 文件操作

查看当前目录：

```bash
pwd
```

列出文件：

```bash
ls -la
```

创建文件夹：

```bash
mkdir my-folder
```

![Linux终端](https://img.j8.je/images/2026/01/27/ZmNl.png)

---

## 文本编辑

使用 nano 编辑文件：

```bash
nano filename.txt
```

使用 cat 查看文件内容：

```bash
cat filename.txt
```

---

## 系统信息

查看内存使用：

```bash
free -h
```

查看磁盘空间：

```bash
df -h
```

这些命令日常使用频率很高，建议收藏！
```

## 什么是 Git？

Git 是一个分布式版本控制系统，用于跟踪代码变化。

![Git工作流程](https://img.j8.je/images/2026/01/27/ZcO7.png)

---

## 基础命令

### 初始化仓库

```bash
git init
```

### 添加文件

```bash
git add .
```

### 提交更改

```bash
git commit -m "提交说明"
```

### 推送到远程

```bash
git push origin main
```

---

## 常用组合

一键提交并推送：

```bash
git add -A && git commit -m "更新内容" && git push
```

---

## 查看状态

```bash
git status
```

```bash
git log --oneline
```

掌握这些命令，日常开发足够用了！

## 为什么搭建博客？

记录学习过程，分享技术心得。

---

## 技术栈

| 组件 | 选择 |
|------|------|
| 框架 | Hexo |
| 主题 | Butterfly |
| 部署 | Cloudflare Pages |
| 图床 | 自建图床 |
| 写作 | Obsidian |

---

## 搭建过程

### 安装 Hexo

```bash
npm install -g hexo-cli
hexo init myblog
cd myblog
npm install
```

### 安装主题

```bash
npm install hexo-theme-butterfly
```

### 本地预览

```bash
hexo server
```

打开 `http://localhost:4000` 即可预览。

---

## 写作流程

1. 手机 Obsidian 写文章
2. 同步到 S3
3. GitHub Actions 自动部署
4. 网站更新

非常方便！
```

---

## 使用方法

1. 在 Obsidian 的 `blog/posts/` 创建这 3 个文件
2. 粘贴内容
3. Remotely Save 同步
4. GitHub Actions 点 **Run workflow**
