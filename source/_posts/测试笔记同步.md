## 什么是 HTML？

HTML（HyperText Markup Language）是一种用于创建网页的标准标记语言。它不是编程语言，而是一种**标记语言**，用于描述网页的结构。

![HTML Logo](https://upload.wikimedia.org/wikipedia/commons/thumb/6/61/HTML5_logo_and_wordmark.svg/240px-HTML5_logo_and_wordmark.svg.png)

## HTML 基本结构

每个 HTML 文档都有一个基本结构：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>我的第一个网页</title>
</head>
<body>
    <h1>欢迎来到我的网站</h1>
    <p>这是一个段落。</p>
</body>
</html>
```

## 常用 HTML 标签

| 标签 | 用途 | 示例 |
|------|------|------|
| `<h1>-<h6>` | 标题 | `<h1>大标题</h1>` |
| `<p>` | 段落 | `<p>这是段落</p>` |
| `<a>` | 链接 | `<a href="url">链接</a>` |
| `<img>` | 图片 | `<img src="url" alt="描述">` |
| `<div>` | 容器 | `<div>内容</div>` |
| `<span>` | 行内容器 | `<span>文字</span>` |

## 为什么学习 HTML？

![Web Development](https://images.unsplash.com/photo-1498050108023-c5249f4df085?w=600)

1. **网页基础** - 所有网页都由 HTML 构建
2. **易于学习** - 语法简单，上手快
3. **就业需求** - 前端开发必备技能
4. **跨平台** - 在任何浏览器中运行
